About HokMob

A cleaner way to follow the NHL.

Live scores, game stats, standings and player stats, all on one fast and easy-to-read site.

Our story

HokMob was created by Sean Odnert, a Bay Area software engineer and lifelong hockey fan. It started with a simple frustration: there wasn't a hockey stats site with a user interface that made following the game enjoyable.

The inspiration came from FotMob, one of the best ways to follow soccer (football). HokMob brings the same idea to hockey, built on the NHL's publicly available data and the community documentation of it, from Drew Hynes' original NHL API notes to today's NHL API Reference.

HokMob is still an active work in progress. It began as a site for family and friends, and it's now open to any hockey fan who finds it useful.
